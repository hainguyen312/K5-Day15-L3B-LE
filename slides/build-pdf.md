# Xuất lại `demo-slides.pdf`

Nguồn: `slides/demo-slides.html` (8 trang 16:9). Sửa HTML rồi chạy (Windows, Chrome hoặc Edge):

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --no-pdf-header-footer --print-to-pdf=demo-slides.pdf slides/demo-slides.html
```

Hoặc mở `slides/demo-slides.html` bằng trình duyệt → Ctrl + P → "Lưu dưới dạng PDF", lề: Không, bật "Đồ hoạ nền".
